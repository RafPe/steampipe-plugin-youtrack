### Added

- Initial read-only Steampipe plugin for JetBrains YouTrack.
- Tables for projects, issues, users, groups, tags, saved queries, articles,
  agile boards, issue comments, and issue work items.
- Server-side qualifier pushdown, pagination, query-limit handling, context
  cancellation, bounded retries, and classified API errors.
- Unit, contract, integration, race, coverage, lint, vulnerability, and
  containerized end-to-end test workflows.
- Documentation, query cookbook, local development commands, and branded
  repository artwork.
